# CSV 분석 스킬

sales.csv(컬럼: `date,product,region,units,revenue`)에서 매출 수치를 집계할 때 이
스킬을 따른다. 숫자를 눈대중으로 계산하지 않는다 — 반드시 `analyze_sales.py`
스크립트를 실행해서 얻은 값만 근거로 쓴다.

## 절차

1. `execute` 도구로 스크립트를 돌린다.

   ```
   python3 skills/csv-analysis/analyze_sales.py <csv경로> --out <결과파일경로>
   ```

   `<csv경로>`는 보통 `data/sales.csv`다. `--out`을 주면 사람이 읽기 좋은 Markdown
   표를 그 경로에 저장하고, 표준출력에는 프로그램이 다루기 쉬운 JSON을 함께 찍는다.

2. 스크립트가 표준출력으로 내보내는 JSON의 `by_product`(제품별 합계),
   `quarter_over_quarter`(직전 분기 대비 증감률)를 결과 해석에 쓴다. JSON을
   직접 파싱하기보다, `--out`으로 저장한 Markdown 결과 파일을 `read_file`로
   다시 읽어 사람이 읽을 답변에 인용하는 편이 컨텍스트를 아낀다 — 전체 CSV를
   대화에 올리지 않는다.

3. 특정 제품·지역의 증감 "원인"은 이 스크립트가 설명하지 않는다. 원인 설명이
   필요하면 `doc-research` 스킬로 넘긴다(문서 근거가 필요한 판단이기 때문).

## 참고

- 이 스크립트는 순수 집계만 한다. 모델의 판단 없이도 항상 같은 입력에 같은
  출력을 낸다 — 그래서 이 스킬의 역할은 "계산은 스크립트에 맡기고, 모델은
  그 결과를 해석해 문장으로 정리하는 것"이다.
- 파일이 크면(수만 행) 전체를 `read_file`로 읽지 말고 이 스크립트로 집계한
  결과만 컨텍스트에 올린다.
