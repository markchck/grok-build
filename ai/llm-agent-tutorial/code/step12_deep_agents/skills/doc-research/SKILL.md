# 문서 조사 스킬

`data/docs/` 아래 제품별 분기 리포트(Markdown)에는 숫자로는 알 수 없는 "왜"가
문장으로 적혀 있다. CSV 집계로 "얼마나 바뀌었는지"를 알았다면, 이 스킬로
"왜 바뀌었는지"의 근거 문장을 찾는다.

## 절차

1. `execute` 도구로 검색 스크립트를 돌린다. 제품명이나 지역명, "감소"·"증가"
   같은 키워드로 관련 문서·문장을 찾는다.

   ```
   python3 skills/doc-research/find_evidence.py <문서디렉터리> <키워드1> [키워드2 ...] --out <결과파일경로>
   ```

   예: `python3 skills/doc-research/find_evidence.py data/docs 노트북 부산 감소 --out results/doc_findings.md`

2. 스크립트는 키워드가 포함된 문장만 골라 `{문서ID}#p{페이지}` 형태의 출처
   꼬리표와 함께 돌려준다. 검색되지 않은 문장은 절대 근거로 쓰지 않는다 —
   이 스킬이 찾아준 문장 밖의 내용을 답변에 지어내지 않는다.

3. `--out`으로 저장한 결과 파일을 `read_file`로 다시 읽어 답변에 인용한다.
   문서 전체를 대화 컨텍스트에 올리지 않는다 — 검색된 문장만 올린다.

## 참고

- 이 스크립트는 단순 키워드 포함 검색이다(4·5단계에서 다룬 Dense/Sparse
  벡터 검색이 아니다). 이 장은 Deep Agents와 Skill 자체가 학습 목표이므로
  검색 방식은 최대한 단순하게 유지했다 — 벡터 검색으로 바꾸고 싶으면
  `docagent`가 아니라 5단계(`code/step05_hybrid_rag/`)의 검색 모듈을
  스킬 스크립트 안에서 재사용하면 된다.
- 근거가 하나도 안 나오면 "이 키워드로는 문서에서 근거를 찾지 못했다"고
  있는 그대로 보고한다. 근거를 지어내지 않는다.
